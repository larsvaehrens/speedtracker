# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/larsvaehrens/speedtracker/security/advisories/new).
Do not report security issues through public issues, discussions, or pull
requests.

Private vulnerability reporting must be enabled in the repository settings once
the repository is public. Until then, the reporting form may not be available.

Include the affected component or version, steps to reproduce, potential impact,
and any supporting evidence. Please avoid accessing data you do not own or
performing tests that could disrupt the service or other users.

We will review reports and coordinate any fixes and disclosure with the
reporter. We do not currently publish response-time guarantees or support older
versions.
