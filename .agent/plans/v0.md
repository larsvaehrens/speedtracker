I want to build an app called "SpeedTracker" for the SpeedRunners game. Speedrunners is a 4-player competitive running game developed by DoubleDutch Games and published by tinyBuild. The game features grappling hooks, power-ups, and interactive environments. Run, jump, swing around, and knock other players off screen. In a city filled with superheroes, getting to crimes becomes a competition on its own. Fortunately there are enough rockets, bombs, grappling hooks, spikes, and other goodies lying around to make the competition fun.

We play this game on a Nintendo Switch in front of the same television. "SpeedTracker" will be our app to track our own stats and how well do against each other.

The app should have good UX. It is paramount that you can quickly tally up the scores and select the map for the ongoing game. Speedrunners is fast paced, and once the map has loaded, there are only few seconds to before the round starts, and it is very competitive so you have to be ready and not fiddling with setup on your phone.

The app should also be responsive and work well on small screens/mobile devices because that is primarily where it will be used.

In the game play you can play different match ups:
- free-for-all, for example, everyone is against each other
- you can create teams, for example, 2 players vs. 2 players
- you can create mixes, for example, 1 vs. 1 vs. 2
- you can also possible to play with just 2 or 3 players, for example 1 vs. 1 vs. 1, or 1 vs. 2
- and lastly head-to-head, 1 vs. 1

When you play solo (i.e. the free-for-all setup), you need to win three rounds in a map to be victorious. When you play with a partner, you need to win four rounds in a map to be victorious, however, if both teammates survive in one round, they gain a round win each, so you have 2 out of four points.

In the game playing ui:
- Before starting a round you should pick who is playing and if any players are in teams.
- There should be a map selector which should open up a modal where you can press any of the standard maps
    - Shown with a title and image (stored in `ressources/maps`).
    - The maps should be sorted according to the above list which is how they appear in the game UI.
    - The first three rows of maps in the modal should contain 5 maps each and with the last two remaining maps on the fourth row, again to match the game UI.
    - It should be possible to start playing a round without selecting the map. Because there is not much time when the map has loaded and is revealed before the round starts. But it should always be required to fill out the map when the round has finished.
- When playing as a team, it should be possible to pick who won the round in the team. So in the game playing UI, there should be a header showing the two players profile picture and name. And right below each player header there should be a button to attribute them with 1 point if they won, and further below that there should be a button to attribute both of them with 1 point each if they both survived.

When setting up a match, you should see the most recent played competitors or most played with competitors. It could also be nice to store the last match setup in local storage, so it is remembered for next time you play. If that is implemented, then it should also be easy to reset the setup completely.

You can only play against your friends. You add friends by entering their username (used for login, not screen name). I don't think we want friendship requests, so just make it possible to add/follow each other.

No landing page, just a sign-in and sign-up form.

Once logged in you will have some options
- create/start match
- see recent match history
    - if you won/lost
    - who played
    - duration of the match
- statistics
- friend list
    - with option to add others
- profile
- profile settings
    - change screen name
    - change avatar (stored in `ressources/heroes/`)

Statistics:

We want a lot of statistics on how various things like:
- overall win rate
- map specific win rate (rank the best to worst maps)
- how well we played against each other (rank the competitors you play the best or worst against)
- how well we play in certain teams (rank the best team combination you are part of)
- are you the one carrying a team mate or are you getting carried by someone else (this is where the point attribution from the team game playing ui comes into play)
- what is our current winning or losing streaks
- what is our all-time highest winning or losing streak

Technical:
- It should be built with Typescript v7
- It should use pnpm for the package mamager
- It should use Vite-plus. Ocx, Oxlint, format, etc.
- It should be built with React, single page application or with server compoments to avoid having a dedicated RESTful backend. I don't care if a framework like Next.js or TanStack Start is used.
- It should be hosted on Cloudflare workers
- I would like to have syncing between users, so someone else playing a match can open the app and see the stats and who they are playing against, the score, etc.
- For auth it can use better-auth, WorkOS or something custom. I don't care.
- Login method should be simple username and password, no need for email or account recovery if it requires setting up an email service or such.
- For styling, it can use TailwindCSS or custom CSS. I don't care.
- For database work, it can use an ORM or raw SQL. I don't care as long as there is an easy way to do local development (e.g. applying migration changes and pushing to the database)
- The sprites/avatars and map images don't have to be hosted on a blob storage, they can be stored in the app files and their file path can be hard-coded
- Database
    - I would like for the map to be a table itself so that you can make some statistics about which maps you are good or bad on
- Hosting:
    - I want to host it on a subdomain, e.g. "speedtracker.example.com", so add instructions in the README for how to run it locally, set up CloudFlare deploys through GitHub
